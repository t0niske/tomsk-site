# Куда сходить в Томске

Городской гид без рекламы: места и события, «Удиви меня», карта Томска в 2D и 3D, каталог заведений и админка для их правки.

## Что где лежит

Корень репозитория — готовый сайт, его можно заливать на хостинг как есть.

| Файл | Что это |
|---|---|
| `index.html` | Главная: подборка мест, каталог всех заведений, события, маршрут дня |
| `map.html` | Карта 2D/3D: реальные дома, рельеф, знаковые здания |
| `tomsk-data.json` | Геоданные карты (дома, улицы, парки, рельеф) |
| `data/venues.json` | **База заведений** — её читают главная и карта, правит админка |
| `admin.php`, `admin-app.js`, `admin-app.css` | Админка: места, фото, часы, заявки, резервные копии |
| `report.php` | Приём заявок «Я владелец / нашли ошибку» с сайта |
| `config.php` | Пароль админки и почта для уведомлений |
| `uploads/`, `reports/`, `data/backup/` | Фото, заявки и копии базы — появляются на хостинге, в git не попадают |
| `src/` | Исходники и скрипты сборки |

## Запуск на хостинге

1. Загрузите содержимое репозитория в корень сайта вместе со скрытыми файлами `.htaccess`. Нужен PHP 7.4+.
2. В `config.php` замените `поменяйте-этот-пароль` на свой пароль (не короче 10 символов).
3. Админка: `https://ваш-сайт/admin.php`.

Подробно — в файле `КАК-ПОЛЬЗОВАТЬСЯ.txt`.

> После запуска база `data/venues.json` живёт на хостинге и меняется из админки. Если заливаете обновление сайта из репозитория поверх, **не перезаписывайте** `data/venues.json` с хостинга, иначе правки из админки потеряются. Сначала скачайте актуальный файл с хостинга и закоммитьте его сюда.

## Сборка из исходников

```bash
# 1. карта: склеивает src/map/*.js в один map.html
cd src/map && python3 build.py && cd ../..
python3 src/finalize.py src/map/map.html "Карта Томска в 2D и 3D: заведения, знаковые здания и прогулки." && cp src/map/map.html map.html

# 2. главная одним файлом (промежуточный шаг)
cd src && cp base.html tomsk.html \
  && python3 places/main.py . && python3 places/catalog_ui.py . \
  && python3 places/venues_ui.py . ../data/venues.json \
  && python3 places/style_ui.py . && cd ..

# 3. многостраничный сайт: assets/, главная и разделы, затем страницы заведений и sitemap.xml
python3 src/pages.py src/tomsk.html .
python3 src/venue_pages.py src/tomsk.html .
```

### Как устроен сайт

| Адрес | Страница |
|---|---|
| `/` | Главная: живая шапка, популярные места, афиша, мини-карта, подборки |
| `/mesta/` | Все места: выбор редакции + полная база с поиском |
| `/sobytiya/`, `/podborki/`, `/derevyannyj-tomsk/`, `/udivi-menya/`, `/o-proekte/` | Разделы |
| `/mesto/<адрес>/` | Страница заведения. Список — `src/venue/pages.json` |
| `assets/site.css`, `assets/site.js`, `assets/venue.js` | Общие стили и скрипты |

Страница заведения собирается из `data/venues.json`: поля `about` (подробно), `look` (что посмотреть, по строке), `tips` (советы, по строке) редактируются в админке. Готовая страница при открытии сама подтягивает свежие часы, цены и тексты из базы, поэтому правки из админки видны сразу. Чтобы добавить новую страницу, впишите место в `src/venue/pages.json` и пересоберите сайт.
