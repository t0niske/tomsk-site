# Куда сходить в Томске

Городской гид без рекламы: места и события, «Удиви меня», карта Томска в 2D и 3D, каталог заведений и админка для их правки.

## Что где лежит

Корень репозитория — готовый сайт, его можно заливать на хостинг как есть.

| Файл | Что это |
|---|---|
| `index.html` | Главная: подборка мест, каталог всех заведений, события, маршрут дня |
| `map.html` | Карта 2D/3D: реальные дома, рельеф, знаковые здания |
| `tomsk-data.json` | Геоданные карты (дома, улицы, парки, рельеф) |
| `data/venues.json` | **База заведений** — её читают главная и карта, правит админка |
| `admin.php`, `admin-app.js`, `admin-app.css` | Админка: места, фото, часы, заявки, резервные копии |
| `report.php` | Приём заявок «Я владелец / нашли ошибку» с сайта |
| `config.php` | Пароль админки и почта для уведомлений |
| `uploads/`, `reports/`, `data/backup/` | Фото, заявки и копии базы — появляются на хостинге, в git не попадают |
| `src/` | Исходники и скрипты сборки |

## Запуск на хостинге

1. Загрузите содержимое репозитория в корень сайта вместе со скрытыми файлами `.htaccess`. Нужен PHP 7.4+.
2. В `config.php` замените `поменяйте-этот-пароль` на свой пароль (не короче 10 символов).
3. Админка: `https://ваш-сайт/admin.php`.

Подробно — в файле `КАК-ПОЛЬЗОВАТЬСЯ.txt`.

> После запуска база `data/venues.json` живёт на хостинге и меняется из админки. Если заливаете обновление сайта из репозитория поверх, **не перезаписывайте** `data/venues.json` с хостинга, иначе правки из админки потеряются. Сначала скачайте актуальный файл с хостинга и закоммитьте его сюда.

## Сборка из исходников

```bash
# 1. карта: склеивает src/map/*.js в один map.html
cd src/map && python3 build.py && cd ../..
python3 src/finalize.py src/map/map.html "Карта Томска в 2D и 3D: заведения, знаковые здания и прогулки." && cp src/map/map.html map.html

# 2. весь сайт: главная, разделы, страницы мест и страницы «куда сходить …»
./build.sh
```

### Как устроен сайт

| Адрес | Страница |
|---|---|
| `/` | Главная: живая шапка с подбором «с кем / когда» и варианты под ней |
| `/kuda-shodit/` и `/kuda-shodit/<сценарий>/` | Ответы на запросы: с девушкой, с друзьями, с детьми, вечером, на выходных, бесплатно (`src/scenarios.py`) |
| `/mesta/` | Все места: выбор редакции + полная база с поиском |
| `/sobytiya/`, `/derevyannyj-tomsk/`, `/o-proekte/` | Разделы |
| `/mesto/<адрес>/` | Страница заведения. Список — `src/venue/pages.json` |
| `assets/site.css`, `assets/site.js`, `assets/venue.js` | Общие стили и скрипты |

Подбор работает по меткам мест (поле `moods`): `date` — вдвоём, `friends` — с друзьями, `kids` — с детьми, `solo` — одному, `night` — вечером, `free` — бесплатно. Метки ставятся в админке.

Страница заведения собирается из `data/venues.json`: поля `about` (подробно), `look` (что посмотреть, по строке), `tips` (советы, по строке) редактируются в админке. Готовая страница при открытии сама подтягивает свежие часы, цены и тексты из базы, поэтому правки из админки видны сразу. Список страниц собирает `python3 src/venue/select_pages.py`: места редакции и заведения OpenStreetMap с адресом и хотя бы одним контактом. Все записи с `origin: supplier` и записи, сопоставленные при импорте CSV, также получают отдельные страницы, в том числе без координат. Адреса уже созданных страниц сохраняются. `./build.sh` автоматически обновляет список и пересобирает страницы. Прежние URL сохраняются; общий список ссылок загружается один раз с `assets/site.js`, а не дублируется внутри каждой карточки.

## Данные

- Здания, улицы, заведения — © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL.
- Рельеф — SRTM.
- Фото знаковых мест — Wikimedia Commons, авторы и лицензии указаны в карточках.
- Описания мест — собственные тексты редакции.

## Импорт приобретённой базы

В `data/venues.json` добавлены записи из предоставленного владельцем CSV. Поле `origin: supplier` обозначает источник импорта, а не независимую проверку. Даты проверки, права и ручной способ сбора автоматически не подтверждаются. Редакционные карточки и OSM сохраняют свои источники.

Повторный импорт: `python3 src/import_venues.py /path/to/file.csv`, затем `./build.sh`. Импорт сопоставляет нормализованное название и адрес либо координаты в пределах 60 м; сведения поставщика для существующих редакционных и OSM-карточек сохраняются отдельно в `supplierDetails`. Отчёт — `data/import-summary.json`. Для повторного импорта выбирайте актуальную копию базы с хостинга.

Карточки без координат доступны в каталоге, но не наносятся на карту. Неизвестные цены и длительность посещения не подменяются предполагаемыми значениями. Режим работы с примечаниями сохраняется как текст и не используется для фильтра «Открыто сейчас».
